# Wiki de uso del ERP

Cómo se hacen las cosas en el ERP de Incoespacio, paso a paso. Una página por tarea, enlazadas entre sí. Se va llenando poco a poco.

## Ventas y obras

- [Meter una obra desde un presupuesto de Presto (.bc3)](ventas/importar-bc3.md)

## Cómo escribir una página

- Una tarea por página, con un título que diga qué se consigue («Meter una obra…», no «BC3»).
- Pasos numerados, con los nombres de los menús y botones tal como salen en pantalla.
- Si una página necesita otra, enlázala en vez de repetirla.
- Añade la página a este índice.
