# Meter una obra desde un presupuesto de Presto (.bc3)

Para pasar al ERP un presupuesto hecho en Presto, se exporta a un archivo `.bc3` y se importa desde Ventas.

## Pasos

1. Entra en **Ventas**.
2. En el menú de arriba, pulsa **BC3 → Importar BC3**.
3. Carga el archivo `.bc3` y elige el **cliente**.
4. Pulsa **Importar**. Se sube y se abre el presupuesto con sus capítulos y partidas.

## A tener en cuenta

- Cada importación crea un presupuesto **nuevo**. No actualiza uno que ya se importó.
